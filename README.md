# Material Didático & Capacitação em Bioinformática 🎓

Repositório dedicado a materiais de ensino, roteiros de aulas práticas e scripts desenvolvidos para disciplinas de Pós-Graduação e workshops técnicos.

## 📚 Disciplinas Ministradas

### 1. Morfometria Geométrica Aplicada
Material desenvolvido para curso de pós-graduação, abordando:
* Digitalização de landmarks em imagens 2D e 3D.
* Análise de Forma (Generalized Procrustes Analysis).
* Estatística Multivariada (PCA, CVA) aplicada à biologia.

### 2. Introdução à Bioinformática no Linux
Roteiros para capacitação de alunos iniciantes:
* Navegação em terminal Linux/Unix.
* Manipulação de arquivos FASTA/FASTQ.
* Automação básica com Shell Script.

## 🎯 Objetivo
O objetivo deste material é democratizar o acesso a ferramentas computacionais para biólogos, facilitando a transição para a análise de dados em larga escala.
